# Як поставити застосунок на iPhone

## Крок 1. Завантажити файли на GitHub (на компʼютері, ~5 хв)

1. Зайди на **github.com** і увійди у свій акаунт.
2. Вгорі справа натисни **«+»** → **New repository**.
3. **Repository name:** `trening`
   Залиш **Public** (безкоштовний хостинг працює тільки з публічними; твої дані тренувань туди НЕ потрапляють, вони живуть лише в телефоні).
   Натисни **Create repository**.
4. На сторінці, що відкрилась, натисни посилання **«uploading an existing file»**.
5. Перетягни туди ці **6 файлів** (більше нічого не треба):
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - `icon-180.png`
   - `icon-192.png`
   - `icon-512.png`
6. Внизу натисни зелену кнопку **Commit changes**.

## Крок 2. Увімкнути сайт

1. У репозиторії відкрий вкладку **Settings** (вгорі).
2. Зліва вибери **Pages**.
3. **Source:** `Deploy from a branch` → **Branch:** `main`, папка `/ (root)` → **Save**.
4. Зачекай 1–2 хвилини й онови сторінку. Зверху зʼявиться посилання виду
   `https://ТВІЙ-НІК.github.io/trening/`

## Крок 3. Поставити на iPhone

1. Відкрий це посилання в **Safari** (саме в Safari, не в Chrome).
2. Натисни кнопку **«Поділитися»** (квадрат зі стрілкою вгору).
3. Прокрути вниз і вибери **«На екран Додому»** → **Додати**.
4. На екрані зʼявиться іконка 🏋️ **Тренування**. Відкривай застосунок тільки через неї.

Після першого відкриття застосунок працює навіть без інтернету.

## Важливо

- **Дані зберігаються тільки в телефоні.** Якщо видалиш іконку застосунку, історія зникне.
- **Оновлення:** якщо я щось допрацюю, просто заміни `index.html` на GitHub (Add file → Upload files). Нова версія підтягнеться, коли відкриєш застосунок 1–2 рази. Твої дані при цьому залишаються.
